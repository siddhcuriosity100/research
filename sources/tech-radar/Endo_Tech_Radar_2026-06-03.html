Endo Tech Radar

New & updated tools across the Endo stack · June 03, 2026
Editor's Note. Today's standout is TimescaleDB (v2.26, Combined 15/15) in Time-series / IoT DB: Postgres-native TSDB with continuous aggregates — the easiest, most full-featured migration path off MongoDB with the entire SQL ecosystem. Two finds tie at a perfect 15 — TimescaleDB v2.26 and libmodbus — both directly serving the planned InfluxDB migration and our RS-485 sensor bus. Also worth a look: mochi-mqtt (embed the broker in the Go API) and Mender (atomic A/B OTA with rollback) as we scale toward 1000 devices.

Declarative YAML-to-firmware system for ESP32/ESP8266 with a huge component library.

Ease4
Qual5
Rel5
Universal wireless library for SX127x, SX126x, LR11x0, LR2021, SX128x. LoRaWAN Class A/C (multicast over C), pre-certified for Class A.
Why it matters: Covers our LoRa radios with pre-certified LoRaWAN Class A; strong fit for the EndNode firmware.

Go backend

mochi-mqtt (server)NEW
v2 · 2026 · Go · MIT
Ease5
Qual4
Rel5
Fully compliant, embeddable high-performance Go MQTT v5 broker for IoT; usable standalone or as a library. Performance comparable to Mosquitto/EMQX.
Why it matters: Embed an MQTT v5 broker directly inside our Go API — removes a separate broker dependency on the cloud side.

MQTT

NanoMQNEW
0.24.13 · 2026-04-21 · C · MIT
Ease4
Qual4
Rel5
Ultra-lightweight, blazing-fast MQTT broker/bus for IoT edge; up to 10x faster than Mosquitto on multi-core; pioneers MQTT over QUIC.
Why it matters: Ideal edge broker for the RPi gateway. CAUTION: a May-2026 advisory flagged hidden REST endpoints / arbitrary file read / DoS in 0.24.13 — pin a patched build and lock down REST.
EMQXNEW
5.x · 2026 · Erlang · Apache-2.0
Ease4
Qual5
Rel4
Highly scalable, reliable MQTT broker for AI/IoT/IIoT and connected vehicles; MQTT over QUIC.
Why it matters: Scalable broker for the Hetzner cloud side; heavier than needed at current device counts but room to grow into.

v2.26 · 2026-03 · C · Apache-2.0 / TSL
Ease5
Qual5
Rel5
PostgreSQL extension for time-series with hypertables, compression and continuous aggregates. v2.26 adds significant analytical query performance gains.
Why it matters: Postgres-native TSDB with continuous aggregates — the easiest, most full-featured migration path off MongoDB with the entire SQL ecosystem.
QuestDBNEW
8.x · 2026 · Java/C++/Rust · Apache-2.0
Ease4
Qual4
Rel5
Purpose-built TSDB (Java/C++/Rust) optimized for ingestion + analytics; ingests InfluxDB line protocol & PostgreSQL wire; SQL queries. 12-36x faster ingest than InfluxDB 3.
Why it matters: Extreme ingest throughput with SQL + InfluxDB line protocol compatibility — strong candidate for the planned InfluxDB migration.
